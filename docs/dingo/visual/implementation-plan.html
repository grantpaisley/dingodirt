04 Built but unplanned

Several capabilities shipped that were never tasks in the original plan — mostly richer modelling and web-UI analytics (see the doc's own 2025-12-30 note).

  • ExtraRide-mode enum — adv / enduro / mtb / other, threaded through matching and stats for per-mode breakdowns.
  • ExtraMulti-resolution geometry — z10 / z14 simplified geometries for fast map rendering at different zoom levels.
  • ExtraHR / speed gradient coloring — per-point gradient coloring of tracks on the map with global min/max normalization for cross-ride consistency.
  • ExtraRange filters — HR and speed range filters that highlight matching portions on the map.
  • ExtraBottom graph pane — an additional time-series graph pane in the web UI beyond the planned three-pane layout.
